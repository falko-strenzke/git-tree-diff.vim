1. INTRODUCTION                                     *git-tree-diff-introduction*

git-tree-diff shows the result of a 'git diff' as a browsable, foldable file
tree.  Selecting a file in the tree opens the two compared versions of that
file in two equally sized windows in Vim's usual |diff-mode|.

==============================================================================
2. COMMANDS                                             *git-tree-diff-commands*

                                                                *:FGitTreeDiff*
:FGitTreeDiff [args]
    Open a new tab page with the diff tree.  All [args] are handed through
    to the underlying 'git diff' invocation, so anything 'git diff' accepts
    works here as well.  Examples: >

        :FGitTreeDiff                    " working tree vs. index
        :FGitTreeDiff --cached           " index vs. HEAD
        :FGitTreeDiff HEAD~3             " working tree vs. HEAD~3
        :FGitTreeDiff main..feature      " two revisions
        :FGitTreeDiff main...feature     " merge base of main vs. feature
        :FGitTreeDiff HEAD -- src/       " limit to a path
<
    The tab contains three windows: the file tree on the far left (showing
    only files with a non-empty diff) and two equally sized diff windows on
    the right with the two compared versions of the selected file.

    Versions taken from a git revision or the index are shown in read-only
    scratch buffers named gtd://{rev}/{path}.  When one side is the working
    tree, the actual file is edited, so changes can be made and saved.

                                                                     *:FGitLog*
:FGitLog [all]
    Open a new tab page with a browsable commit log based on the output of
    'git log --graph --decorate'.  With the optional argument "all",
    '--all' is appended to the git command.

    Pressing <CR> on a commit shows - right of the log window and created
    on first use - the file tree of that commit's changes and the two diff
    windows, exactly as for |:FGitTreeDiff|.  The commit is compared
    against its first parent; a root commit is compared against the empty
    tree.  Selecting another commit reuses the same windows.

                                                                  *:FGitPrList*
:FGitPrList
    Show a list of the open GitHub pull requests of the current repository
    in a window at the bottom.  Requires the 'gh' command line tool to be
    installed and authenticated.  Pressing <CR> on a pull request opens it
    in a new tab page, see |git-tree-diff-pr|.

                                                           *:FGitPrOpenComment*
:FGitPrOpenComment
    In a pull request file window: open the comment thread on the current
    line in the comment window at the far right.  Also mapped to
    <Leader>fc there.  In the comment list: same as <CR>.

                                                          *:FGitPrCommentsOpen*
                                                         *:FGitPrCommentsClose*
                                                        *:FGitPrCommentsToggle*
:FGitPrCommentsOpen
:FGitPrCommentsClose
:FGitPrCommentsToggle
    Open, close or toggle the list of all comments of the pull request in a
    window at the bottom, see |git-tree-diff-pr-comments|.

                                                                 *:FGitPrReply*
:FGitPrReply
    Reply to the selected comment: in the comment list the comment under
    the cursor, otherwise the comment last opened in the comment window.
    The reply is written in a new markdown buffer; |:write| sends it to
    GitHub.  Also mapped to "r" in the comment window.

                                                            *:FGitPrNewComment*
:FGitPrNewComment
    Add a new comment to the pull request conversation.  The comment is
    written in a new markdown buffer; |:write| sends it to GitHub.

==============================================================================
3. TREE WINDOW                                              *git-tree-diff-tree*

The first two lines show the repository name and the compared revisions.
Directories end with a "/" and can be folded with the usual |fold-commands|.

Mappings in the tree window:

    <CR>            On a file: show its diff in the right-hand windows.
                    On a directory: toggle its fold.
    o               Same as <CR>.
    <2-LeftMouse>   Same as <CR>.
    q               Close the tab page.

==============================================================================
4. LOG WINDOW                                                *git-tree-diff-log*

The log window shows the raw 'git log --graph --decorate' output.  Commits
can be navigated with the usual motions.

Mappings in the log window:

    <CR>            Show the file tree and diffs for the commit on or
                    above the cursor.
    o               Same as <CR>.
    <2-LeftMouse>   Same as <CR>.
    <C-n>           Jump to the next commit line.
    <C-p>           Jump to the previous commit line.
    q               Close the tab page.

==============================================================================
5. PULL REQUESTS                                              *git-tree-diff-pr*

All GitHub access goes through the 'gh' command line tool, which must be
installed and authenticated (see 'gh auth login').

|:FGitPrList| shows the open pull requests.  Opening one creates a new tab
page with a foldable tree of the changed files on the left - like the
GitHub "Files changed" view - and a file window on the right.  Opening a
file from the tree shows the pull request version of the file with these
gutter signs:

    ┃ (GitTreeDiffPrAdd)      line added or changed by the pull request
    ▁ (GitTreeDiffPrDel)      lines were deleted above this line
    C (GitTreeDiffPrComment)  the line has review comments

If the pull request branch is checked out in the working tree, the real
file is edited so it can be modified and saved; otherwise a read-only
buffer named gtd-pr://{rev}/{path} is shown.  A file deleted by the pull
request is shown in its base version.

In the file window, <Leader>fc (or |:FGitPrOpenComment|) on a line with a
"C" sign opens the comment thread of that line in a markdown window at the
far right.  In the comment window "q" closes it and "r" starts a reply.

                                                     *git-tree-diff-pr-comments*
|:FGitPrCommentsOpen| lists all comments of the pull request in a window at
the bottom: first the conversation comments, then the review comments
grouped by file and line.  Each comment is shown with a header (author,
time, location; replies are marked with "↳") and a preview line.

Mappings in the pull request list and in the comment list:

    <CR>            Open the pull request / show the comment.
    o               Same as <CR>.
    <2-LeftMouse>   Same as <CR>.
    <C-n> / <C-p>   Comment list only: jump to the next/previous comment.
    q               Close the window.

Replies (|:FGitPrReply|) and new conversation comments (|:FGitPrNewComment|)
are written in a scratch markdown buffer; |:write| sends the comment to
GitHub and closes the buffer.  The first line ("<!-- ... -->") is an
instruction and is stripped before sending.

6. CONFIGURATION                                   *git-tree-diff-configuration*

                                                        *g:git_tree_diff_width*
g:git_tree_diff_width
    Width of the tree window in columns.  Default: 34

                                                    *g:git_tree_diff_log_width*
g:git_tree_diff_log_width
    Width of the log window in columns once the tree and diff windows are
    shown.  Default: 50

                                             *g:git_tree_diff_pr_comment_width*
g:git_tree_diff_pr_comment_width
    Width of the pull request comment window in columns.  Default: 50

                                           *g:git_tree_diff_pr_comments_height*
g:git_tree_diff_pr_comments_height
    Height of the pull request comment list window in lines.  Default: 12

                                                       *g:git_tree_diff_gh_cmd*
g:git_tree_diff_gh_cmd
    The 'gh' executable used for all GitHub access.  Default: "gh"
